getmyoffer

NAME
----
getmyoffer - get one of your offers (deprecated)

SYNOPSIS
--------
getmyoffer
		--offer-id=<value>

DESCRIPTION
-----------
Returns your offer with the given id.  Deprecated;  use getoffer instead.

OPTIONS
-------
--offer-id
		The id of the offer.

EXAMPLES
--------
Get one of your offers:
$ ./haveno-cli --password=xyz --port=9998 getmyoffer --offer-id=<offer-id>
