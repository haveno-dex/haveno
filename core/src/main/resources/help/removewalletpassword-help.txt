removewalletpassword

NAME
----
removewalletpassword - remove the wallet password

SYNOPSIS
--------
removewalletpassword
		--wallet-password=<value>

DESCRIPTION
-----------
Removes the wallet password, decrypting the wallet.

OPTIONS
-------
--wallet-password
		The wallet password.

EXAMPLES
--------
Remove the wallet password:
$ ./haveno-cli --password=xyz --port=9998 removewalletpassword --wallet-password=abc
