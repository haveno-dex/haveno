unlockwallet

NAME
----
unlockwallet - unlock the wallet

SYNOPSIS
--------
unlockwallet
		--wallet-password=<value>
		--timeout=<value>

DESCRIPTION
-----------
Stores the wallet password in memory for a number of seconds, unlocking the wallet.

OPTIONS
-------
--wallet-password
		The wallet password.

--timeout
		The number of seconds the wallet password is held in memory.

EXAMPLES
--------
Unlock the wallet for 5 minutes:
$ ./haveno-cli --password=xyz --port=9998 unlockwallet --wallet-password=abc --timeout=300
