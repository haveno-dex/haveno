changepassword

NAME
----
changepassword - change the Haveno account password

SYNOPSIS
--------
changepassword
		--account-password=<value>
		--new-account-password=<value>

DESCRIPTION
-----------
Changes the Haveno account password.

OPTIONS
-------
--account-password
		The current Haveno account password.

--new-account-password
		The new Haveno account password.

EXAMPLES
--------
Change the account password:
$ ./haveno-cli --password=xyz --port=9998 changepassword --account-password=abc --new-account-password=xyz
