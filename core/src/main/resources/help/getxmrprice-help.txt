getxmrprice

NAME
----
getxmrprice - get current market XMR price

SYNOPSIS
--------
getxmrprice
		--currency-code=<value>

DESCRIPTION
-----------
Returns the current market XMR price for the given currency-code.

OPTIONS
-------
--currency-code
		The three letter code of the currency, e.g., EUR, USD, BCH, ...

EXAMPLES
--------
Get the current XMR market price in Euros:
$ ./haveno-cli --password=xyz --port=9998 getxmrprice --currency-code=eur
