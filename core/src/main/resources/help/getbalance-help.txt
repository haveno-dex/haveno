getbalance

NAME
----
getbalance - get wallet balances

SYNOPSIS
--------
getbalance
		--currency-code=<value>

DESCRIPTION
-----------
Returns full balance information for the Haveno XMR wallet.
All amounts are shown in XMR.

OPTIONS
-------
--currency-code
		An optional three letter Haveno wallet crypto currency code (xmr).

EXAMPLES
--------
Show full XMR wallet balance information:
$ ./haveno-cli --password=xyz --port=9998 getbalance
