setwalletpassword

NAME
----
setwalletpassword - set or change the wallet password

SYNOPSIS
--------
setwalletpassword
		--wallet-password=<value>
		--new-wallet-password=<value>

DESCRIPTION
-----------
Encrypts the wallet with a password, or sets a new password on the encrypted wallet.

OPTIONS
-------
--wallet-password
		The wallet password.

--new-wallet-password
		The optional new wallet password.

EXAMPLES
--------
Encrypt the wallet with a password:
$ ./haveno-cli --password=xyz --port=9998 setwalletpassword --wallet-password=abc

Set a new wallet password:
$ ./haveno-cli --password=xyz --port=9998 setwalletpassword --wallet-password=abc --new-wallet-password=xyz
