confirmpaymentreceived

NAME
----
confirmpaymentreceived - confirm payment has been received

SYNOPSIS
--------
confirmpaymentreceived
		--trade-id=<value>

DESCRIPTION
-----------
Confirm the trade's payment has been received from the buyer.

OPTIONS
-------
--trade-id
		The id of the trade.

EXAMPLES
--------
Confirm payment received:
$ ./haveno-cli --password=xyz --port=9998 confirmpaymentreceived --trade-id=<trade-id>
